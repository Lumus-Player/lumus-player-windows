# Lumus Player para Windows

## Português

Instalador oficial do Lumus Player para Windows. **Versão 1.0.0 (131).**

### [⬇ Baixar para Windows](https://github.com/Lumus-Player/lumus-player-windows/releases/download/windows/Lumus-Player-Setup-131.exe)

Para PCs de 64 bits com Windows 10 (versão 1809 ou posterior) ou Windows 11.

1. Baixe o instalador pelo link acima.
2. Abra o arquivo e siga as instruções de instalação.
3. Abra o Lumus Player e entre na sua conta.

Use suas próprias listas. O Lumus Player não fornece conteúdo.

[Site oficial](https://lumusplayer.com/#desktop) · [Precisa de ajuda?](https://lumusplayer.com/suporte)

## English

Official Lumus Player installer for Windows. **Version 1.0.0 (131).**

### [⬇ Download for Windows](https://github.com/Lumus-Player/lumus-player-windows/releases/download/windows/Lumus-Player-Setup-131.exe)

For 64-bit PCs running Windows 10 (version 1809 or later) or Windows 11.

1. Download the installer using the link above.
2. Open the file and follow the installation steps.
3. Open Lumus Player and sign in to your account.

Use your own playlists. Lumus Player does not provide content.

[Official website](https://lumusplayer.com/en#desktop) · [Need help?](https://lumusplayer.com/en/suporte)
