# Lumus Player para Windows

Distribuição oficial do aplicativo Lumus Player para computadores com Windows. Este repositório contém instaladores, manifestos de atualização e hashes dos arquivos; não contém o código-fonte do aplicativo.

## Português

- Compatibilidade: Windows 10, versão 1809 ou superior, e Windows 11; computadores de 64 bits (x64).
- [Site oficial e download](https://lumusplayer.com/#desktop)
- [Instaladores e arquivos da versão Windows](https://github.com/Lumus-Player/lumus-player-windows/releases/tag/windows)
- Suporte: [suporte@lumusplayer.com](mailto:suporte@lumusplayer.com)

Baixe o instalador .exe, abra o arquivo e siga as etapas do assistente. Depois, abra Lumus Player pelo menu Iniciar e entre na sua conta Lumus. Para conferir o arquivo baixado, compare seu hash SHA-256 com a entrada correspondente em SHA256SUMS.txt, anexado à mesma release.

O Lumus Player é um reprodutor de mídia. A pessoa fornece suas próprias listas e precisa ter autorização para acessar o conteúdo. O Lumus não inclui, vende, hospeda nem distribui canais, filmes ou séries. Os planos liberam funções do software, sem fornecer conteúdo.

## English

Official Lumus Player distribution for Windows 10 version 1809 or later and Windows 11, on 64-bit (x64) PCs. This repository contains installers, update manifests and file hashes, not the application source code.

Download the .exe installer from the [official release](https://github.com/Lumus-Player/lumus-player-windows/releases/tag/windows), open it and follow the setup steps. Then open Lumus Player from the Start menu and sign in to your Lumus account. To verify the downloaded file, compare its SHA-256 hash with the matching entry in SHA256SUMS.txt attached to the same release.

Lumus Player is a media player. Users provide their own playlists and must have permission to access their content. Lumus does not include, sell, host or distribute channels, movies or series. Plans unlock software features without supplying content.

[Official website](https://lumusplayer.com/en#desktop) · [Support](mailto:suporte@lumusplayer.com)
